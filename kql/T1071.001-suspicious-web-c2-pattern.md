# T1071.004 — DNS C2 Activity

**MITRE ATT&CK:** T1071.004 — DNS  
**Tactic:** Command and Control  
**Data Source:** `DnsEvents`  
**Severity:** High

### Behavior

Hosts repeatedly query a known command-and-control domain over DNS.

### Detection Logic

Identifies DNS queries to a known malicious C2 domain and summarizes activity by client IP, including the first and last observed query and total query count.

### False Positives

Legitimate systems communicating with a domain that has been incorrectly classified or subsequently repurposed.

### Detection

```kql
DnsEvents
| where query_name contains "update-cdn-service.xyz"
| summarize
    first_seen = min(timestamp),
    last_seen = max(timestamp),
    query_count = count()
    by client_ip
| order by query_count desc

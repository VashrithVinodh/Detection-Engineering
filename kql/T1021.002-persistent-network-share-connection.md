# T1021.002 — Persistent Network Share Connection

**MITRE ATT&CK:** T1021.002 — SMB/Windows Admin Shares  
**Tactic:** Lateral Movement  
**Data Source:** `ProcessEvents`  
**Severity:** Medium

### Behavior

The Windows `net use` utility is used with `/PERSISTENT:YES` to create a network share connection that persists across user logons.

Attackers may use persistent network connections to maintain access to remote systems or establish access to network resources after lateral movement.

### Detection Logic

Detects execution of `net use` with the `/PERSISTENT:YES` option.

### False Positives

Legitimate administrators and users may configure persistent network drives for:

- Shared file servers
- Departmental network drives
- Enterprise applications
- Administrative workflows
- User profile or data storage

Additional context such as the remote host, share name, executing user, and parent process should be considered when investigating an alert.

### Detection

```kql
ProcessEvents
| where process_commandline contains "net use"
| where process_commandline contains "/PERSISTENT:YES"
| project timestamp, hostname, username, process_commandline

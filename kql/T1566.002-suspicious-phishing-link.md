# T1566.002 — Suspicious Phishing Link

**MITRE ATT&CK:** T1566.002 — Spearphishing Link  
**Tactic:** Initial Access  
**Data Source:** `Email`, `PassiveDns`, `InboundNetworkEvents`  
**Severity:** High

### Behavior

An external email contains a link associated with infrastructure observed communicating with suspected attacker-controlled systems.

### Detection Logic

The detection correlates suspicious inbound network activity with DNS infrastructure and identifies emails containing links to domains associated with that infrastructure.

This detection was developed from an investigation in which attacker-controlled infrastructure was identified through inbound network activity before being observed in phishing emails sent to employees.

### False Positives

Legitimate emails containing links to infrastructure that has been incorrectly classified as suspicious.

### Detection

```kql
let attacker_ips =
InboundNetworkEvents
| where user_agent has "Opera/8.64"
| where timestamp between (datetime("2024-05-03") .. datetime("2024-05-05"))
| distinct src_ip;

let sus_domains =
PassiveDns
| where ip in (attacker_ips)
| distinct domain;

Email
| where link has_any (sus_domains)
| where recipient has "solvisystems.com"
| project timestamp, sender, recipient, subject, link

# T1071.004 — DNS C2 Beaconing

**MITRE ATT&CK:** T1071.004 — DNS  
**Tactic:** Command and Control  
**Data Source:** `DnsEvents`  
**Severity:** Medium

### Behavior

A host repeatedly queries the same DNS domain within a short period, which may indicate automated command-and-control beaconing.

### Detection Logic

Detects clients making 10 or more DNS queries to the same domain within a 10-minute window.

### False Positives

Legitimate applications that repeatedly resolve the same domain, DNS-heavy applications, monitoring systems, and software update services.

### Detection

```kql
DnsEvents
| summarize
    query_count = count(),
    first_seen = min(timestamp),
    last_seen = max(timestamp)
    by client_ip, query_name, bin(timestamp, 10m)
| where query_count >= 10
| project client_ip, query_name, query_count, first_seen, last_seen
| order by query_count desc
